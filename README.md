# Arcanum
Arcanum adalah sistem rekomendasi berbasis pengetahuan (Knowledge-Based System) yang membantu pemain menentukan artifact dan weapon yang sesuai untuk karakter tertentu berdasarkan role dan kebutuhan build. Pemain cukup bertanya dalam bahasa sehari-hari, misalnya, "Saya ingin membuat build Raiden Shogun untuk Reaction DPS. Apa yang cocok?"
